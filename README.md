# whisperwriter.iydebu.com

Landing + download page for [WhisperWriter](https://github.com/iydebu/whisper-writer), a local speech-to-text app for Windows.
Static single page on GitHub Pages. The installer is sold on Gumroad (pay what you want).

- `index.html` - the page (no build step)
- `og.png` - share image; `tools/og.html` renders it and the Gumroad cover/thumbnail
- `tools/phone_check.py` - 390px phone screenshot + overflow check
